# Requirement

## Requirement
1. **同源双后端编译**：同一份标准 AST 同时编译至隐式求值链与 `build123d`/OCCT 精确 B-Rep 链。对含 B-Rep 不支持的自由隐式特征显式返回 `OUT_OF_DOMAIN`，严禁静默降级为三角网冒充解析实体。
2. **多维几何同构与回读核验**：双后端需校验双向 Hausdorff 距离 $< 10^{-3}\text{ mm}$、连通分量数与孔洞亏格（Betti 数/欧拉示性数）100% 一致；导出 `.step` 后执行重新读回（Round-Trip Re-import），核对拓扑有效性、体积相对偏差 $< 10^{-4}$，并同步输出工艺清单 JSON。

## Verification
- 通过 50+ 棵随机合法 AST 的双后端一致性测试、任意刚体平移旋转蜕变测试（Metamorphic Testing）以及相切/近共面退化预警测试集。
