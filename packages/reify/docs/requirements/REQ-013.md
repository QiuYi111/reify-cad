# Requirement

## Requirement
1. **3D 样条与无扭转扫掠**：实现 `BSplineCurve3D`（Boehm 节点插入 + 包络定理可微最近点 + 控制多边形区间下界）与 `SweepAlongSpline`（Double Reflection Rotation-Minimizing Frame，曲率自交检查 $\kappa_{\max} R_{\max} < 0.95$，精确 Lipschitz 界与 OCCT 扫掠体编译）。
2. **可微认证张量积 NURBS 曲面壳**：实现 `BSplineSurface` 与 `BSplineSurfaceShell`（控制网细分 BVH 严格下界 + 2D 阻尼牛顿投影含四条边界曲线 + 包络定理对 3D 控制网点求导 + OCCT 原生 `Geom_BSplineSurface` 缝合加厚实体）。
3. **多截面参数化放样**：实现 `LoftSketches`，双后端编译为平滑放样体。

## Verification
- 3D 弯管与自由曲面壳通过原生 NURBS STEP 回读与双向 Hausdorff 校验；5,000 个随机 3D 盒区间下界零违背；控制网点梯度与中心差分一致；`solve()` 自动鼓包避让内部障碍物并通过 `verify() == PASS`。
