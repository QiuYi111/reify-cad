# Requirement

## Requirement
1. **单均匀介质 Dirichlet WoS 探针（修正统计收敛阶）**：仅处理单均匀介质稳态 Laplace / 稀疏源 Poisson 方程与 Dirichlet 边界，步长采用 `unsigned_boundary_distance_lower(x)`；固定样本量 IID 抽样下，样本均值方差为 $O(1/N)$、**标准误 $\operatorname{SE}(\bar{X}_N) = O(1/\sqrt{N})$、均值随机误差为 $O_p(1/\sqrt{N})$**，输出正态近似 95% 置信区间 $\bar{X}_N \pm 1.96 s/\sqrt{N}$（跨阈值返回 `UNKNOWN`）。
2. **含平面应力面外 $F_{zz}$ 迭代的准静态 MLS-MPM（正向求解）**：
   - **平面应变（Plane Strain）**：施加 $F_{zz}=1, F_{xz}=F_{yz}=0$；
   - **平面应力（Plane Stress）**：对可压缩超弹性本构严格满足 $\sigma_{zz}=0$，在物质点积分处通过闭式解或局部标量 Newton 迭代求解未知面外变形 $F_{zz}$；
   - 将 FE-ADR 粘性阻尼机制迁移适配至 MLS-MPM 网格动量步，采用带分母保护残差 $r_F = \|R\|_2 / (\|F_{\text{int}}\|_2 + \|F_{\text{ext}}\|_2 + F_0) \le \tau_F$ 配合动能比判据，M3 仅承诺正向平衡求解。
3. **几何光路遮挡检查**：基于安全步进仅校验视场锥与光束通道的几何挡光。

## Verification
- 在球壳 Laplace 解析解上验证 WoS 方差 $O(1/N)$、标准误 $O(1/\sqrt{N})$ 收敛及 95% CI 覆盖率；在薄片卡扣（平面应力，核验 $\sigma_{zz} \approx 0$）与厚曲梁（平面应变）算例上对比独立非线性 `CalculiX` 解。
