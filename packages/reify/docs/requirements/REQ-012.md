# Requirement

## Requirement
1. **第一类全双后端工程特征**：新增 `ExtrudeSketch`、`TaperedExtrude`（拔模角可微并严格保持 $L=1$）、`Frustum`、`RevolveSketch`（全周与扇角旋转）、`Offset`（要求子体 $L=1$）、`Shell`（封闭与顶面敞口 `open_top=True`）、`LinearPattern` 与 `CircularPattern`。
2. **全栈集成**：全部 M5 节点支持 `(B, N, 3)` 批量求值、`sample_parametric_points`、`cover_surface`、`affine.eval_affine_box` 保守区间界、`SmoothBooleanProxy` 与 OCCT B-Rep 1:1 编译。

## Verification
- 真实注塑外壳（拔模 + 敞口抽壳 + 旋转凸台 + 环形孔阵）通过 STEP 回读、双向 Hausdorff 校验、`solve()` 拔模角/壁厚反求、M2 最小壁厚与 M3 `CalculiX ccx_2.23` 静力分析。
