# Requirement

## Requirement
1. **类型系统硬隔离**：`BRepFinalized` 严禁继承 `Node`，且禁止回插 `Union`/`Intersect`/`Subtract`/`Transform`/`SmoothUnion`/`Part`/`solve`/`Offset`/`Shell`（传入必须抛出 `TypeError`）。
2. **显式知情同意与双等级标记**：`finalize_brep(..., irreversible=True, reason=...)` 与 `import_step_terminal(..., irreversible=True, reason=...)` 必须显式确认不可逆并填写非空原因；区分 `CertificationTier.CORE_CERTIFIED` 与 `CertificationTier.BREP_ESCAPED` 并写入 `craft.json`。
3. **末端细节与 B-Rep 终审**：支持 `LocalFilletEdges`、`LocalChamferEdges`、`LocalDraftFaces`、`verify_brep_clearance` 与 `export_finalized_step`。

## Verification
- 运行时拦截 `BRepFinalized` 回插解析树；拒绝未显式声明 `irreversible=True` 或空 `reason`；完成末端倒角/导入外部 STEP 后的间隙四态复核与合法 STEP 导出。
