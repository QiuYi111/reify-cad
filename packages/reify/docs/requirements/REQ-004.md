# Requirement

## Requirement
1. **有界闭合正则实体准入**：前置校验输入实体的连通分支闭合非空，不满足时返回 `OUT_OF_DOMAIN`。
2. **上下界严格分离的三分支间隙判定（严禁用下界未过判 `FAIL`）**：检验最小分离距离与安全间隙阈值 $m \ge 0$ 时：
   - **`PASS`（严格下界 $d_{\min} > m$）**：各连通分支内点均认证落在对方 `OUTSIDE`，且双向覆盖采样片全部满足 `external_clearance_lower > r_s + m`；
   - **`FAIL`（必须具备显式穿透证人或上界 $d_{\max} \le m$）**：仅当找到某点 $p \in A$ 被认证为 $B$ 的 `INSIDE`（标记 `PENETRATION`），或找到一对显式表面/实体证人点 $(p \in A, q \in B)$ 满足 $\|p - q\| - \varepsilon_{\text{num}} \le m$（标记 `CLEARANCE_VIOLATION`）时，才允许判 `FAIL`；
   - **`UNKNOWN`（区间跨阈值 $d_{\min} \le m < d_{\max}$）**：细分预算耗尽仍既未证毕 $d_{\min} > m$、也未找到 $d_{\max} \le m$ 违规证人时，必须诚实返回 `UNKNOWN`。
3. **双向 Hausdorff 冻结认证与四态返回**：`world_shell` 终审严格检查双向 Hausdorff 距离 $\le \varepsilon_{\text{freeze}}$；所有验证器统一输出 `PASS / FAIL / UNKNOWN / OUT_OF_DOMAIN`。

## Verification
- 构造三类必测用例：① 直径 0.2mm 细针穿粗网（必返 `FAIL: PENETRATION`）；② 小件完全缩在大件内部（必返 `FAIL: PENETRATION`）；③ 伪距离场保守下界 $d_{\text{lower}} < m$ 但真实间隙 $> m$ 且限制细分深度为 0（必返 `UNKNOWN`，绝不误判 `FAIL`）。
