# Requirement

## Requirement
1. **显式单位、局部原点坐标与纯函数语义**：所有长度强制显式单位（默认 `mm`，角度 `deg`），原语在各自局部原点坐标系求值后再经刚体变换组合以抑制大坐标消减误差；静态禁止依赖离散面/边索引的拓扑选择器。
2. **参数三级分类与可微锚点（`Anchor`）**：区分 `SmoothParam`、`PiecewiseParam` 与 `DiscreteVariant`；`Anchor(origin(θ), axes(θ))` 全程为依赖 `Param` 的可微张量表达式。
3. **分作用域冻结（终审仅认双向 Hausdorff 距离）**：
   - `freeze="world_shell"`：**最终冻结认证唯一采用双向 Hausdorff 距离** $d_H(S_{\text{old}}, S_{\text{new}}) \le \varepsilon_{\text{freeze}}$（或经严格证明的零等值面位移界）；隐式场差仅允许做快速预筛，严禁直接作为最终冻结判定依据；
   - `freeze="datum_axis"`：仅锁定通孔/螺柱轴线位姿与直径，允许附着板厚沿轴向自由伸缩。

## Verification
- 验证子特征 `Anchor` 自动微分梯度与中心差分一致；构造 $f_{\text{new}} = 2 f_{\text{old}}$（零等值面未变但场差非零）与边界微膨胀两类用例，验证 `world_shell` 基于双向 Hausdorff 距离零误判。
