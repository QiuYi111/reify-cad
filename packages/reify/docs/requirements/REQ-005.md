# Requirement

## Requirement
1. **按具体表达式精确声明光滑阶数的代理契约（`SmoothBooleanProxy`）**：
   - 一阶优化默认采用**二次多项式 `smin`（全局 $C^1$）**，二阶优化可选**三次多项式 `smin`（全局 $C^2$）**；若选用 R-函数系统必须显式登记其不可微奇异集（如 $R_2$ 在 $(0,0)$ 不可微，严禁笼统宣称全局 $C^1$）；
   - 多项式 `smin` 的 $k/4$ 仅作为场值偏差参考而非未证明的几何空间位移界，代理仅负责内部优化引导，不承担任何安全证明。
2. **两级可行性优先多起点局部求解与硬几何终审**：归一化参数空间并发运行多起点搜索（默认 `initial_batch_size=64` Sobol 起点），收敛后**强制切回真实硬布尔几何调用 `verify()` 终审**，诚实返回 `FEASIBLE_FOUND` 或 `NO_FEASIBLE_FOUND_IN_BUDGET`。

## Verification
- 在带多个 PCB 禁区障碍物及侧壁破壁风险的支架案例上，`solve()` 自动收敛输出 `FEASIBLE_FOUND`，且最终硬几何复核与独立 OCCT 校验全部 `PASS`。
