# Requirement

## Requirement
1. **显式初始毛坯与单工序保守刀柄避让公式**：输入包含目标零件的初始毛坯 $P_{\text{stock}} \supseteq P_{\text{part}}$ 与夹具障碍 $O_{\text{fixture}}$，第一版采用单工序保守准则（非切削刀柄 $T_{\text{nc}}$ 全程不得碰初始毛坯与夹具，切削刃 $C_{\text{cut}}$ 不得过切目标零件）：
   - 保守无碰撞刀位：$F_{\text{cons}} = \neg \Big( (P_{\text{part}} \oplus \check{C}_{\text{cut}}) \cup \big((P_{\text{stock}} \cup O_{\text{fixture}}) \oplus \check{T}_{\text{nc}}\big) \Big)$；
   - 安全进刀平面泛洪得 $F_{\text{reach}}$，**实际可切除余料体积**定义为 $M_{\text{removable}} = (P_{\text{stock}} \setminus P_{\text{part}}) \cap (F_{\text{reach}} \oplus C_{\text{cut}})$。
2. **精确零填充 Local-ROI 3D FFT 与动态字节守卫**：按 $N_{\text{fft}} = \text{next\_fast\_len}(N_{\text{roi}} + K_{\text{tool}} - 1)$ 零填充，动态核算输入/频谱/FFT 工作区字节上限（超限报 `OUT_OF_DOMAIN`），并与球树查询测速对比。
3. **方向性壁厚与结构块体厚度分离（不冒充全局最小壁厚）**：
   - `check_directional_wall_thickness`：测量表面采样点在预设内法向锥角 $\theta_{\text{cone}}$ 内到**非拓扑邻接对向表面**的距离，承诺指定法向锥内的方向性薄壁筛查（`PASS / FAIL / UNKNOWN`），不宣称任意几何的全局最小壁厚证明；
   - `compute_structural_thickness`：调用成熟 EDT（`scipy.ndimage` / Meijster）与最大内切球计算块体尺度并计入双侧体素误差。

## Verification
- 对照暴力离散三维卷积验证含初始毛坯的零填充 FFT 逐体素 100% 等价；在斜交薄壁与 T 型筋算例上验证 `check_directional_wall_thickness` 筛查准确。
