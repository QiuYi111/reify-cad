# Requirement

## Requirement
1. **FCM 成熟库适配与模态虚域局部模式筛查**：优先复用/适配成熟免贴体有限元框架（如 `NGSolve / xfem`），采用切割单元自适应积分与对称稳定化 Nitsche 边界；模态分析分别定义物理域与虚域刚度/质量贡献（独立测试 $\alpha_K, \alpha_M$ 或引入特征值稳定化，删除“同步缩放必然消除伪模态”的错误假设），通过**物理域应变能/动能参与比**滤除虚域局部伪模态并用 MAC 矩阵配对物理模态。
2. **离线三级 GCI 验证与在线两级快筛分离**：离线 Benchmark 强制跑通三级网格（$h, h/2, h/4$ Richardson 外推 GCI）；在线默认采用两级快筛并如实标注近似属性；M3 仅交付正向求解。
3. **指定真实三维体网格器的双通道 `CalculiX` 桥接**：
   - **通道 A（标准解析 B-Rep 件）**：将 OCCT B-Rep 送入 **`Gmsh`（OpenCASCADE 内核特征保持四面体网格器，备选 `Netgen / CGAL Mesh_3`）** 生成保留锐边与孔棱的 `C3D4/C3D10` 体网格导出 `.inp`；
   - **通道 B（纯隐式复杂件）**：调用 `CGAL Mesh_3`（隐式域）或 `Isosurface Stuffing` 生成有界二面角四面体网格，校核最小体积与缩放雅可比后送入真实 `CalculiX` 验证。

## Verification
- 在斜置铁木辛柯悬臂梁、Kirsch 带孔板及模态算例上通过离线三级 GCI 与虚域伪模态滤除验证，且 `Gmsh` 通道 A 与隐式通道 B 导出的 `.inp` 均在真实 `CalculiX` 求解吻合。
