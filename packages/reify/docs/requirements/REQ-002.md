# Requirement

## Requirement
1. **双精度分级与尺度相关误差预算**：`solve()` 快筛使用 `float32`，`verify()` 近边界认证强制切换至 `float64`（或双精度区间后端）；在规定局部几何尺度 $S \le S_{\max}$ 与 AST 深度 $D \le D_{\max}$ 内定义误差预算 $\varepsilon_{\text{num}}(S, D) = \varepsilon_{\text{abs}} + \varepsilon_{\text{rel}}(D)\cdot S$（超界报 `OUT_OF_DOMAIN`），禁止将固定 $1\,\mu\text{m}$ 宣称为无条件数学上界。
2. **原语级 Lipschitz 登记与三项距离/分类接口解耦**：为所有基础原语逐一登记 Lipschitz 上界 $L \ge 1$ 成立条件，并严格拆分为：
   - `classify_point(x) -> INSIDE | OUTSIDE | UNCERTAIN`（$|f(x)| > L\varepsilon_{\text{num}}$ 时给出确定分类）；
   - `external_clearance_lower(x) = f(x)/L - eps_num(S, D)`（**仅在点 $x$ 已认证为 `OUTSIDE` 时有效**，提供外部净空下界）；
   - `unsigned_boundary_distance_lower(x) = max(0, |f(x)|/L - eps_num(S, D))`（全空间有效，供 WoS 步进）。
3. **采样解耦、带保证等级的 `DistanceResult` 与并列溯源**：
   - 拆分为静态认证覆盖采样 `cover_surface(max_radius=r_s)` 与局部参数可微采样 `sample_parametric_points(params)`；
   - 距离查询返回 `DistanceResult`，显式区分 `CERTIFIED_INTERVAL`（仿射算术/对偶 GJK）与 `SOLVER_TOLERANCE`（OCCT `BRepExtrema` 的 `SetDeflection` 结果，其合法证人点对提供真实最小距离上界）；
   - `provenance(x)` 在平局容差内返回并列生效节点 `active_branches: list[NodeID]`。

## Verification
- 在大坐标偏移、布尔拐角、内部负场值及非均匀缩放场景下，对照 OCCT 验证 `classify_point`、`external_clearance_lower` 与 `unsigned_boundary_distance_lower` 严格符合不等式契约。
