# Requirement

## Requirement
1. **完整 2D 草图原语与环**：支持 `LineSeg2D`、`Arc2D`、`QuadBezier2D`、`CubicBezier2D`、`BSpline2D`（通过精确 Boehm 节点插入线性矩阵拆分为 Bézier 段），以及 `Loop2D`（含 `polygon` 拐角倒圆/倒角、`circle`、`rounded_rect`、`closed_bspline`）和带多内孔的 `Sketch2D`。
2. **精确 1-Lipschitz 有符号距离与自适应用缠绕数**：`Sketch2D` 对外环与内孔输出精确有符号距离（$L=1$），支持 `(N, 2)` 与批量 `(B, N, 2)` 求解。
3. **包络定理（Envelope Theorem）自定义 `autograd`**：2D Bézier/B-Spline 最近点采用控制多边形 AABB 剪枝 + 保护牛顿迭代，反向传播采用包络定理解析求导至控制点，不反传牛顿循环。
4. **严格保守 2D 区间下界与 OCCT 2D 面编译**：提供基于 de Casteljau 控制多边形凸包的保守 `interval_bound_2d`，并 1:1 编译为原生 `Geom2d`/`Geom_BSplineCurve` OCCT 2D 面。

## Verification
- 10,000 点高密暴力真值对拍距离误差 $< 10^{-5}\text{ mm}$；10,000 个随机 2D 盒区间下界零违背；控制点梯度与 `float64` 中心差分相对误差 $< 10^{-5}$；`solve()` 自动优化样条控制点避障并通过 `verify() == PASS`。
