# Requirement

## Requirement
1. **显式联合分布与严格 IID 抽样良率（`check_yield`）**：显式指定完整的联合误差分布模型，强制采用独立同分布（IID）伪随机抽样（严禁把准随机 Sobol 序列代入二项置信公式），直接调用成熟 `scipy.stats.binomtest` 输出 Clopper-Pearson 二项置信下界。
2. **独立确定性实体条件校验（`check_material_condition`）**：独立于随机抽样，按 GD&T / Requicha 偏移实体边界理论确定性校核最大实体条件（`MMC`）与最小实体条件（`LMC`）装配无干涉性。

## Verification
- 对照解析多维联合高斯装配概率真值验证重复试验下 95% Clopper-Pearson 下界实际覆盖率 $\ge 95\%$，且 `MMC/LMC` 极值判定与解析销孔真值一致。
