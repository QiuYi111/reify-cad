# Requirement

## Requirement
1. **闭环图拦截与前置非穿透/非包含校验**：通过关节连接图拦截闭环机构（返回 `OUT_OF_DOMAIN`）；运动推进开始前（$s=0$）必须先证明两实体未穿透且未相互包含。
2. **包含转动副与移动副的完整区间速度上界**：针对无量纲路径参数化轨迹 $q(s), s \in [0, 1]$（记 $q'_k = dq_k/ds$），设转动副集合为 $\mathcal{R}$（$R_k^{\max}$ 为关节轴 $k$ 到所有下游运动实体最远点的距离），移动副集合为 $\mathcal{P}$，则子区间 $[s, s+\Delta s]$ 上的相对速度上界为：
   $$V_{\text{upper}}(s, \Delta s) = \sum_{k \in \mathcal{R}_A \cup \mathcal{R}_B} \|q'_k\|_{L^\infty([s, s+\Delta s])} R_k^{\max} + \sum_{p \in \mathcal{P}_A \cup \mathcal{P}_B} \|q'_p\|_{L^\infty([s, s+\Delta s])}$$
   优先调用成熟 `FCL / hpp-fcl` CCD，并辅以基于**外部真实分离净空下界** $d_{\text{sep\_lower}}(A(s), B(s))$（而非无符号边界距离）的保守推进与近接触二分；未证毕时返回 `UNKNOWN`。
3. **结构化工具操作包络**：独立定义螺丝刀与 L 型内六角扳手（批头/短臂、杆部/长臂、最低摆动扇角及轴向退刀通道）几何模型。

## Verification
- 在含转动副+移动副串联滑台摆臂（解析碰撞位姿已知）与 L 型扳手干涉算例上 100% 检出穿模，且闭环四连杆输入返回 `OUT_OF_DOMAIN`。
